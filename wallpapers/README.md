## Comment les utiliser / les appliquer (à mettre aussi dans ton produit pour tes clients)

### 💻 PC — Wallpaper Engine (Steam)
1. Wallpaper Engine → **Create Wallpaper** → sélectionne un fichier `.html`.
2. **Apply**. L'animation tourne à l'infini sur le bureau.

### 🌐 PC — sans logiciel
Ouvre le `.html` dans un navigateur, plein écran (**F11**).

### 📱 Téléphone — via une vidéo
iOS/Android n'affichent pas du HTML en fond : enregistre l'écran (10-20 s) pendant que le `.html`
tourne en plein écran, puis applique la vidéo avec une app (**TapWallpaper**, **Live Wallpaper**, **Zedge**).
