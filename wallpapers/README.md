## 💻 Sur PC — via Wallpaper Engine (Steam)

C'est la meilleure option : Wallpaper Engine sait afficher des fonds « Web » (HTML), donc l'animation
tourne à l'infini, sans boucle visible.

1. Ouvre **Wallpaper Engine** → **Create Wallpaper**.
2. Choisis d'importer un **fichier local** et sélectionne le `.html` du thème (ex. `hyperspace.html`).
3. Wallpaper Engine crée le fond → **Apply**. C'est appliqué sur ton bureau.

> Pour **vendre** cette version : téléverse le fichier `.html` (ou le dossier du wallpaper exporté
> depuis Wallpaper Engine) dans le produit correspondant sur Gumroad.

## 🌐 Sur PC — sans logiciel

Ouvre simplement le `.html` dans ton navigateur et passe en plein écran (**F11**). Idéal pour
prévisualiser ou pour enregistrer une vidéo (voir ci-dessous).

## 📱 Sur téléphone — via une vidéo

iOS/Android n'affichent pas directement du HTML en fond d'écran : il faut passer par une **vidéo**.

1. Ouvre le `.html` en plein écran sur un PC (F11).
2. Enregistre l'écran **10 à 20 s** (OBS Studio gratuit, ou l'enregistreur d'écran de ton téléphone
   si tu ouvres la page dessus).
3. Applique la vidéo comme fond animé via une app : **TapWallpaper**, **Live Wallpaper**, **Zedge**…

> Pour **vendre** la version téléphone : téléverse la vidéo `.mp4` obtenue dans ton produit Gumroad.
